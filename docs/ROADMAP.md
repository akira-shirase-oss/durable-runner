# Roadmap

Step order follows the contract: model, journal, execute, maintain — each with
its proof before the next starts.

| Step | Content | Gate | Status (2026-11-19) |
|---|---|---|---|
| **D0 — scaffold + model** | Workspace, docs, the state machine: transitions, invalid states, identities, limits; deterministic tests under a fake clock | Every invalid transition named and refused; reducer is pure and replayable | **Done** — 7 domain tests: named refusals, bounded retries, deterministic backoff |
| **D1 — journal** | Framing (version/length/seq/checksum), append + fsync, exclusive writer lock, snapshot, manifest, replay; torn-tail fixtures | The four contract failure cases proven: ack durability, duplicate-key return, second-writer refusal, torn tail | **Done** — since hardened: group commit on a writer thread (D-015), frame v2 with a header checksum and a recorded batch (D-032), a torn batch dropped whole (D-043), golden-file format tests (D-046), owner-only files (D-038); 34 journal tests |
| **D2 — execute** | Allowlisted HTTP handlers, step checkpoints, delayed work, bounded retries (jitter + deadlines), cancellation, effect reconciliation | Vanished-reply reconciliation proven; at-least-once with one idempotency key; cancel stops scheduling, never undoes a remote action | **Done** — actor runtime: bounded in-flight dispatch, deadline sweep → reconcile probe, `{op_key}/{step}` idempotency keys, delayed starts |
| **D3 — maintain** | Compaction into a new generation, 7-day terminal expiry preserving live state + dedup deps, consistent backup/restore, bounded diagnostics, admission reserve | Crash-during-compaction opens one complete generation; restore drill on a real directory | **Done** — live drill: kill -9 → replay recovery, compact → generation 2, backup → restore → second server recovers identical state. Found + fixed: commit-time envelopes (replay reproduced `finished_at=0`, expiring everything instantly). Bounded diagnostics deferred to load work. **2026-11-16:** the two contract cases now have tests, not only a drill — a crash at each compaction step reopens one complete generation (and found a real bug: a crashed compaction refused every later one), and full disk is a 503 with readiness false (injected free-space probe); retention deletes superseded generations |
| **D4 — surface + ship** | CLI polish, inspection UI, one noncritical pilot workflow, the load plan (10→100 submits/s w/ fsync policy, replay @100k transitions, stall/full/compaction cases) | The ship gate: documented crash survival + a second developer runs/inspects/backs up/restores | **Done** — CLI, server, inspector covering every API op (strict CSP, two-key handling, light/dark tokens, D-053; before/after screenshots in `perf/ui/`), verified backups and locked restores (D-034, D-044), reply deadlines, SIGTERM drain, connection + per-address limits (D-045, D-052), the pilot, kill -9 drills (`perf/drill.py`, D-042), `scripts/check.sh` on hosted CI (D-041), the failure-case map (`docs/FAILURE_CASES.md`), versioned journal records accepting v1 forever (D-054; restart-to-ready 800k → 1.7 s), the rollback format guard (D-056), and the droplet deploy package + rehearsals (`docs/DEPLOY.md`, D-055). Million-request battery on the GitHub runner (run 44440111562): five scenarios green; `sustained` refused honestly at the machine's ~85 completions/s ceiling — kept in `perf/results/`, classified RUNNER (`perf/LOAD_MATRIX.md`). The droplet's own ceiling + rehearsal numbers are the deploy-gate measurement (`docs/DEPLOY.md` §capacity planning, §7) |

adapter. Each gets its own execution and ownership contract before work starts.
